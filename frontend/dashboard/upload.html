How it works

  1. Put the photos in one folder for this event

    Any name works, for example "Event photos". JPG or PNG only, so export RAW or HEIC files to JPG first. Subfolders are fine.

  2. Optional: sort them yourself

    You don't have to. Photos you leave unsorted are sorted automatically by AI using the event's guide below, and anything it isn't sure about stays private. If you'd rather decide yourself, create these two folders inside and move photos into them. Your folders always win over the AI.

    Event photos/ ├── Photos for everyone/ ├── Private photos/ └── (anything else here is sorted by AI)
  3. Upload the event folder

    Drag the "Event photos" folder onto the box below, or click Choose folder and select it.

  4. Keep this page open until it says "All photos uploaded"

    If your connection drops, click Retry failed uploads. Uploading the same folder again is safe, since duplicates are skipped.
